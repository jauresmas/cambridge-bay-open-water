# Sources et licences

Toutes les données sont ouvertes et lues sans compte. Les fichiers téléchargés restent dans `data/` (non versionné) ; seuls les résultats dérivés sont publiés dans `resultats/` et `figures/`.

| Donnée | Producteur | Accès utilisé | Licence ou conditions |
|---|---|---|---|
| Sentinel-1 EW GRDM (HH, HV) | ESA, programme Copernicus | Planetary Computer, collection `sentinel-1-grd` (STAC, COG) | Conditions Copernicus Sentinel : usage libre, mention de la source |
| Sentinel-2 L2A | ESA, programme Copernicus | Planetary Computer, collection `sentinel-2-l2a` | Conditions Copernicus Sentinel |
| Landsat 8 et 9, collection 2, niveau 2 (température de surface) | USGS, NASA | Planetary Computer, collection `landsat-c2-l2` | Domaine public (USGS) |

## Toponymie

Les noms des lacs suivent la Base de données toponymiques du Canada : le nom inuinnaqtun d'abord, puis le nom anglais quand il existe (« Iqaluktuuttiaq / Greiner Lake »). Le hameau est nommé Cambridge Bay (Iqaluktuuttiaq).
